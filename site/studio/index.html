    When

    The Instagram carousel goes out a few hours later so it doesn't compete with the Reel.

    Where

    A target only posts if a matching channel is connected in Buffer.

    Save & ship

    1. Save to the box repo. Writes the media and post.json into <box>/glassbox/.
    2. Dry run. Shows the exact Buffer posts and checks the media URLs.
    3. Ship it. Commits and pushes glassbox/, waits for GitHub Pages, then schedules every post in Buffer.
