# Security

Glassbox is a static website: it runs no server code of ours and stores no data
about visitors, so there is little to breach. We still care about:

- anything that could make a Glassbox page load code or content from another site,
- a way around the Content Security Policy on our pages,
- anything in the studio or scripts that could run with more access than intended.

Please report issues privately through
[GitHub security advisories](https://github.com/glassboxhow/glassboxhow.github.io/security/advisories/new)
rather than a public issue. We'll reply as soon as we can and credit you if you like.
